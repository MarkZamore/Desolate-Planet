# Как пользоваться справочником

* Оглавление находится на боковой панели слева.
* На многих страницах есть интерактивные сцены. Кнопки ![Плюс](assets/diagrams/plus.png)
и ![Минус](assets/diagrams/minus.png) меняют масштаб. Перетаскивайте сцену левой кнопкой мыши, чтобы повернуть камеру, и правой, чтобы её сдвинуть.

# Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты для хранения и перемещения ресурсов. Вместо комнаты, заставленной сундуками, можно собрать компактную МЭ-сеть, и это только начало.

Applied Energistics рассчитан на совместную работу с другими модами и позволяет автоматизировать их механизмы. Сеть может по одному запросу изготовить все промежуточные компоненты и конечный продукт, поддерживать запас расходников, производя их по мере необходимости, или просто перемещать предметы по базе.

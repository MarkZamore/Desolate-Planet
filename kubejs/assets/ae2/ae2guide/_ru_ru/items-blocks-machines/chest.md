# МЭ-сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ-сундук объединяет <ItemLink id="terminal" />, <ItemLink id="drive" /> и <ItemLink id="energy_acceptor" /> в миниатюрную сеть. Он может работать как самостоятельное хранилище, но вмещает только одну [ячейку хранения](../items-blocks-machines/storage_cells.md).

МЭ-сундук удобен для работы с конкретной ячейкой. Его встроенный терминал видит только её содержимое, а [устройства](../ae2-mechanics/devices.md) общей сети обращаются ко всему [сетевому хранилищу](../ae2-mechanics/import-export-storage.md), включая все МЭ-сундуки.

Нажмите на верхнюю грань, чтобы открыть встроенный терминал. Через неё можно подавать предметы в ячейку, но нельзя извлекать их. Любая другая грань открывает окно со слотом для ячейки и настройкой приоритета. Автоматически вставить или вынуть саму ячейку можно только с грани, на которой виден её слот.

Его можно вращать с помощью <ItemLink id="certus_quartz_wrench" />.

МЭ-сундук имеет небольшой запас энергии AE. Если сеть не оснащена [энергохранилищем](../items-blocks-machines/energy_cells.md), одновременная передача большого числа предметов может обесточить сундук.

Терминал можно покрасить при помощи <ItemLink id="color_applicator" />.

## Настройки

У МЭ-сундука те же настройки, что у <ItemLink id="terminal" /> и <ItemLink id="crafting_terminal" />, но он не поддерживает <ItemLink id="view_cell" />.

<a name="cell-status-leds" />

## Цветовые индикаторы ячеек

Цвет индикатора в МЭ-сундуке показывает состояние установленной ячейки:

| Цвет | Состояние |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный | Пустая |
| Синий | Есть содержимое |
| Оранжевый | Достигнут предел [типов](../ae2-mechanics/bytes-and-types.md). Новые типы не поместятся |
| Красный | Закончились свободные [байты](../ae2-mechanics/bytes-and-types.md). Больше предметов не поместится |
| Чёрный | Нет питания или [канала](../ae2-mechanics/channels.md) |

<a name="priority" />

## Приоритет

Приоритет задаётся кнопкой с гаечным ключом в правом верхнем углу окна ячейки. Сеть сначала помещает предметы в хранилище с наивысшим приоритетом. При равном приоритете она выбирает хранилище, где предмет уже есть. Если [в ячейке настроен фильтр](cell_workbench.md), сеть ведёт себя так, как будто соответствующие предметы уже лежат в ней. При извлечении сеть начинает с наименьшего приоритета. Так хранилища с высоким приоритетом заполняются, а с низким постепенно освобождаются.

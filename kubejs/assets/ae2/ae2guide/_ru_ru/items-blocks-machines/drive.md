# МЭ-накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

МЭ-накопитель — [устройство](../ae2-mechanics/devices.md), которое подключает [ячейки хранения](storage_cells.md) к [сетевому хранилищу](../ae2-mechanics/import-export-storage.md). В нём десять слотов, по одной ячейке на слот.

Сами ячейки можно вставлять и извлекать автоматически, например воронками или шинами AE2.

Его можно вращать с помощью <ItemLink id="certus_quartz_wrench" />.

<a name="cell-status-leds" />

## Цветовые индикаторы ячеек

Цвет светодиода в накопителе показывает состояние ячейки:

| Цвет | Состояние |
| :----- | :------------------------------------------------------------------------------- |
| Зелёный | Пустая |
| Синий | Есть содержимое |
| Оранжевый | Достигнут предел [типов](../ae2-mechanics/bytes-and-types.md). Новые типы не поместятся |
| Красный | Закончились свободные [байты](../ae2-mechanics/bytes-and-types.md). Больше предметов не поместится |
| Чёрный | Нет питания или у накопителя нет [канала](../ae2-mechanics/channels.md) |

<a name="priority" />

## Приоритет

Приоритет задаётся кнопкой с гаечным ключом в правом верхнем углу окна. Сеть сначала помещает предметы в хранилище с наивысшим приоритетом. При равном приоритете она выбирает хранилище, где предмет уже есть. Если [в ячейке настроен фильтр](cell_workbench.md), сеть ведёт себя так, как будто соответствующие предметы уже лежат в ней. При извлечении сеть начинает с наименьшего приоритета. Так хранилища с высоким приоритетом заполняются, а с низким постепенно освобождаются.

# Справочник

<ItemImage id="guide" scale="8" />

### В этой книге собраны сведения об Applied Energistics 2.

* Оглавление находится на боковой панели слева.
* На многих страницах есть интерактивные сцены. Кнопки ![Плюс](../assets/diagrams/plus.png)
  и ![Минус](../assets/diagrams/minus.png) меняют масштаб. Чтобы повернуть камеру, перетащите сцену левой кнопкой мыши. Чтобы сдвинуть её, используйте правую кнопку.

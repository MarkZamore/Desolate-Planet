# Вырезатель

<BlockImage id="inscriber" scale="8" />

Вырезатель штампует схемы и [процессоры](processors.md) с помощью [прессов](presses.md), а также измельчает предметы
в пыль. Принимает энергию AE2 (AE) и Fabric/Forge (E/FE). В режиме доступа по сторонам предметы попадают в разные
ячейки в зависимости от стороны подачи. Чтобы развернуть блок, используйте <ItemLink id="certus_quartz_wrench" />.
Вырезатель можно настроить на автоматическую выдачу готовых предметов в соседний инвентарь.

Размер входного буфера регулируется. Если один инвентарь питает несколько вырезателей, уменьшите буфер. Так материалы
распределятся между устройствами, вместо того чтобы сначала заполнить первый вырезатель до 64 предметов.

Четыре пресса используются для изготовления [процессоров](processors.md).

Именной пресс позволяет переименовывать блоки, как на наковальне. Так можно помечать устройства в <ItemLink id="pattern_access_terminal" />.

<a name="settings" />

## Настройки

* Можно распределять предметы по ячейкам по стороне подачи или разрешить подачу с любой стороны. Во втором случае
  ячейку выбирает внутренний фильтр, а из верхней и нижней ячеек нельзя извлечь предметы.
* Можно включить автоматическую выдачу предметов в соседний инвентарь.
* Большой входной буфер удобен для одного вырезателя с ручной подачей. Маленький помогает распределить ресурсы
  между несколькими устройствами.

<a name="the-gui-and-sidedness" />

## Интерфейс и стороны блока

При доступе по сторонам выбор ячейки зависит от грани блока, с которой работают трубы или воронки.

![Интерфейс вырезателя](../assets/diagrams/inscriber_gui.png) ![Стороны вырезателя](../assets/diagrams/inscriber_sides.png)

A. **Верхняя входная ячейка** доступна с верхней грани. Предметы можно подавать и извлекать.

B. **Средняя входная ячейка** доступна через боковые грани. Предметы можно только подавать.

C. **Нижняя входная ячейка** доступна с нижней грани. Предметы можно подавать и извлекать.

D. **Выходная ячейка** доступна через боковые грани. Предметы можно только извлекать.

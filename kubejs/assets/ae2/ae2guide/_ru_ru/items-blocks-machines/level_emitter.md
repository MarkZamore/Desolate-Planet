# Излучатель уровня

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/level_emitter.snbt" />
</GameScene>

Излучатель уровня подаёт сигнал красного камня в зависимости от количества выбранного предмета
в [сетевом хранилище](../ae2-mechanics/import-export-storage.md).

Энергетический излучатель работает по запасу [энергии](../ae2-mechanics/energy.md) в сети.

Предметы и жидкости можно перетащить в ячейку фильтра из JEI или REI, даже если их нет в инвентаре.

Нажмите ПКМ по ячейке, держа ёмкость с жидкостью, например ведро или резервуар. Фильтр запомнит саму жидкость.

Излучатели устанавливаются как [кабельные модули](../ae2-mechanics/cable-subparts.md).

Среди [устройств](../ae2-mechanics/devices.md) излучатели уровня выделяются тем, что им *не* нужен [канал](../ae2-mechanics/channels.md).

<a name="settings" />

## Настройки

*   Порог можно сравнивать в режиме «больше или равно» либо «меньше».
*   С <ItemLink id="crafting_card" /> можно подавать сигнал во время изготовления предмета или запускать изготовление сигналом.

<a name="upgrades" />

## Улучшения

Излучатель уровня поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="fuzzy_card" /> позволяет фильтровать по степени износа или игнорировать NBT предмета.
*   <ItemLink id="crafting_card" /> даёт возможность связать сигнал с созданием предметов.

<a name="crafting-functionality" />

## Управление автосозданием

Установите <ItemLink id="crafting_card" />, чтобы переключить излучатель в режим создания.

Доступны два режима.

В первом излучатель подаёт сигнал, пока [автокрафт](../ae2-mechanics/autocrafting.md) создаёт выбранный предмет через
<ItemLink id="pattern_provider" />. Так можно включать энергоёмкую установку только на время работы.

Во втором сигнал запускает изготовление предмета. Это подходит для бесконечных ферм и установок, где результат
выпадает случайно. Излучатель создаёт виртуальный [шаблон](patterns.md) [автокрафта](../ae2-mechanics/autocrafting.md)
для предмета из ячейки фильтра. У <ItemLink id="pattern_provider" /> **не должно быть** другого шаблона на этот предмет.

В таком шаблоне нет ингредиентов. Сеть включает сигнал и ждёт поступления готового предмета. Это позволяет запускать
бесконечные фермы без входных ингредиентов или установки с рекурсивным рецептом, который обычный автокрафт не понимает.
Например, «1 булыжник → 2 булыжника», если у вас есть установка, удваивающая булыжник.

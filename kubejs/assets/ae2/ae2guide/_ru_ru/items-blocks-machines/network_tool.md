# Сетевой инструмент

<ItemImage id="network_tool" scale="4" />

Сетевой инструмент — разновидность [гаечного ключа](wrench.md) со встроенной диагностикой сети и отделением для [карт улучшений](upgrade_cards.md). Он позволяет быстро разбирать устройства и снимать [компоненты](../ae2-mechanics/cable-subparts.md) с кабеля, как обычный ключ. Поворачивать блоки им нельзя.

В инструменте девять слотов для [карт улучшений](upgrade_cards.md). Если он лежит в вашем инвентаре, карты можно взять из него прямо в интерфейсе любого устройства AE2.

Нажмите ПКМ по любой части сети, чтобы открыть окно диагностики. Такое же окно открывается при нажатии на <ItemLink id="controller" />. В нём видны:

*   Количество занятых каналов сети.
*   Переключатель общей единицы измерения энергии: AE или E/FE.
*   Запас [энергии](../ae2-mechanics/energy.md) и максимальная ёмкость сети.
*   Подача и расход энергии.
*   Список [устройств](../ae2-mechanics/devices.md) и компонентов сети.

При работе с [подсетями](../ae2-mechanics/subnetworks.md) окно также помогает понять, принадлежат ли два кабеля или устройства одной сети.

## Скрытие фасадов

<a href="facades.md">Фасады</a> скрываются, пока вы держите сетевой инструмент в любой руке.

Со скрытыми за ними блоками можно взаимодействовать, не снимая фасады.

# Пространственный якорь

<BlockImage id="spatial_anchor" p:powered="true" scale="8"/>

Для работы [устройств](../ae2-mechanics/devices.md) AE2 чанки сети должны быть загружены. Если загружена только часть сети, она может работать неправильно. Пространственный якорь принудительно загружает все чанки, которые занимает его сеть. Достаточно провести один кабель через границу чанка.

Якорь загружает чанки и на другом конце [квантового моста](quantum_bridge.md), если обе стороны находятся в одном измерении. При соединении с Нижним миром поставьте якорь и на своей базе, и в Нижнем мире.

По умолчанию якорь также включает случайные такты в загруженных чанках. Этот параметр можно отключить в конфигурации AE2.

Якорь можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

## Настройки

*   В интерфейсе якоря можно выбрать общую единицу измерения энергии: AE или E/FE.
*   Якорь может показывать в мире голограмму загружаемых чанков.

## Энергопотребление

Расход [энергии](../ae2-mechanics/energy.md) пространственного якоря рассчитывается по формуле:

e = 80 + (x\*(x+1))/2

Здесь x — количество загружаемых чанков.

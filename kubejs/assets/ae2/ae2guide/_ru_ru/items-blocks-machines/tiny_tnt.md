# Крохотный динамит

<BlockImage id="tiny_tnt" scale="8" />

Небольшой динамит для небольших взрывов. Пригодится для создания пар <ItemLink id="quantum_entangled_singularity" />.

В конфигурации можно отключить разрушение блоков этим динамитом. Тогда игроки смогут делать сингулярности без риска испортить постройки, даже если на сервере отключены обычный динамит и взрывы криперов.

# Беспроводные терминалы

<Row>
  <ItemImage id="wireless_terminal" scale="4" />

  <ItemImage id="wireless_crafting_terminal" scale="4" />
</Row>

Это переносные версии проводных [терминалов](terminals.md). Интерфейсы совпадают с проводными аналогами. Вместо слотов для <ItemLink id="view_cell" /> у них слоты для [карт улучшений](upgrade_cards.md).

Чтобы привязать терминал к сети, вставьте его в правый верхний слот <ItemLink id="wireless_access_point" />, подключённой к этой сети. На слоте изображён терминал со стрелкой под ним.

Для работы терминал должен быть в радиусе <ItemLink id="wireless_access_point" />.

Терминалы можно зарядить в <ItemLink id="charger" />.

# Беспроводной терминал

<ItemImage id="wireless_terminal" scale="4" />

Переносной вариант обычного терминала. Просматривайте [сетевое хранилище](../ae2-mechanics/import-export-storage.md) и заказывайте предметы в системе [автокрафта](../ae2-mechanics/autocrafting.md) в любом месте в радиусе <ItemLink id="wireless_access_point" />.

## Интерфейс

Подробнее на странице [терминалов](terminals.md).

## Улучшения

Беспроводной терминал поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="energy_card" /> увеличивает ёмкость батареи.

# Беспроводной терминал создания

<ItemImage id="wireless_crafting_terminal" scale="4" />

Этот терминал работает как обычный беспроводной, но в нём есть сетка крафта. Ингредиенты в ней автоматически пополняются из [сетевого хранилища](../ae2-mechanics/import-export-storage.md). Учитывайте это, когда забираете результат с зажатой клавишей Shift.

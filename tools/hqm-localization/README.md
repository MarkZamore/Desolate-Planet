# Локализация книги Hardcore Questing Mode

Мод `desolate_hqm_localization` показывает русский отчёт MAT и семь русских названий глав, когда клиент Minecraft использует `ru_ru`. Для остальных языков HQM использует исходные названия и отчёт. Изменения действуют на клиентской стороне и не требуют мода на выделенном сервере.

Отчёт взят из `config/hqm/default/description.txt` версии Desolate Planet 1.8.6.0. Перевод применяется только к отчёту с совпадающей SHA-256 после нормализации переводов строк. Если владелец сервера отредактировал отчёт, книга показывает его текст. Главы переводятся по исходному названию в представлении списка, при вычислении области нажатия и в подсказках. В файлах мира остаются английские имена глав и исходный отчёт. [Авторский выпуск сборки](https://www.curseforge.com/minecraft/modpacks/desolate-planet/files/8267330)

## Сборка

Понадобятся Python 3.11 или новее, JDK и библиотеки уже подготовленного клиента Minecraft 1.20.1 Forge 47.4.20. В примере `$run` указывает на отмеченный каталог задач в `artifacts/agent-runs`, `$runtime` на корень тестовой установки, `$game` на проверенный экземпляр Desolate Planet.

```powershell
python -B LocalSources/Desolate-Planet/tools/hqm-localization/build.py `
    --shared-libraries "$runtime/Minecraft/Launcher/Shared/libraries" `
    --hqm-jar "$game/mods/HQM-1.20.1-5.16.0-forge.jar" `
    --output-directory "$run/hqm-localization-build"
```

Скрипт проверяет SHA-256 каждого входного JAR и выводит размер и SHA-256 результата. Код компилируется сразу для имён методов, используемых Forge 47.4.20 в выпущенном клиенте. Патчи Mixin адресуют только методы HQM из версии 1.20.1-5.16.0. При смене платформы или версии HQM сверьте целевые методы и выполните проверку книги заново.

В сценарии `Build-RespawnProbe.ps1 -WithBookLocales` книга HQM после входа загружает английский, русский и снова английский ресурсы. Проверяются все семь названий и отчёт MAT, сформированный штатным движком переноса строк HQM. Прогон использует один объект вступительной страницы, чтобы проверить обновление её кэша.
